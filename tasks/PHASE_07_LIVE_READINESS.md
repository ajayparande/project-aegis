# Phase 7 — Live Readiness Assessment (No Automatic Activation)

## Goal
Produce a documented go/no-go decision. This task does not authorise live trading.

## Required reviews
- [ ] Independent quantitative review of out-of-sample results.
- [ ] Sufficient paper-trading observation and regime coverage, with limitations stated.
- [ ] Current SEBI/exchange/broker requirements checked.
- [ ] Current Zerodha API terms, authentication, static IP and rate limits checked.
- [ ] Data-use rights and licensing checked.
- [ ] Secret management and infrastructure security reviewed.
- [ ] Idempotency, duplicate-order prevention, reconciliation and kill switch designed and tested.
- [ ] Incident response and manual supervision defined.
- [ ] Costs and capital-at-risk disclosed in plain language.
- [ ] Explicit user approval obtained for any separate live-trading implementation.

## Default decision
NO-GO unless every applicable requirement is satisfied. Passing this assessment does not guarantee profitability.
