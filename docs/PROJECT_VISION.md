# Project Vision

## Purpose
Create a transparent, evidence-driven platform that helps a non-expert user research Indian-market trading approaches. AI assists with education, research hypotheses, code explanations and experiment summaries. It does not act as an unchecked financial decision-maker.

## Intended user experience
The user should be able to open a dashboard and understand:
- What the system is researching.
- Which experiments ran and on what data.
- Which strategies failed and why.
- Whether a candidate passed validation.
- Simulated positions, P&L, drawdown and costs.
- Data freshness, system health and budget usage.

Explanations must use plain language and distinguish measured facts from hypotheses.

## Success definition
The first successful product is not a profitable bot. It is a reliable research laboratory that:
- Reproduces results from recorded inputs and code versions.
- Avoids look-ahead and survivorship bias as far as the available dataset permits.
- Includes realistic trading costs and execution assumptions.
- Reports failures honestly.
- Can run paper trading without placing broker orders.
- Stays within the approved budget.

## Out of scope initially
- Live trading or automatic order placement.
- Options/futures execution.
- High-frequency trading.
- Leverage or borrowed trading capital.
- Autonomous strategy deployment.
- Self-modifying risk controls.
- Paid news feeds, premium data vendors, VPS or multiple paid LLM subscriptions unless later approved.
