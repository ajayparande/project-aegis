# Budget and Cost Controls

## Initial ceiling
Total initial project budget: ₹10,000. This is a ceiling, not a spending target. Preserve unused funds.

## Planning allocation (indicative)
- Market-data/API subscription: reserve up to ₹2,500 only if needed (e.g. five months at a verified ₹500/month Connect price; recheck current terms before purchase).
- LLM API: reserve up to ₹1,500 with a hard provider-side limit where available and application-level token/call budgets.
- Hosting/additional data: reserve up to ₹500 only with written justification.
- Contingency/unspent reserve: ₹5,500.
- Open-source software and local development: ₹0 planned.

Actual prices, taxes, eligibility credits, provider terms and data licences must be verified at purchase time. Do not assume ChatGPT subscription includes API credits.

## Spending controls
1. No purchase or subscription without user approval.
2. Log provider, purpose, date, expected recurring cost and cancellation method.
3. Set provider-side spending caps where supported.
4. Add application-level per-run and monthly LLM budgets.
5. Stop non-essential AI workflows when budget thresholds are reached.
6. No paid cloud server in initial milestones.
7. No paid second LLM unless a documented evaluation proves measurable benefit.
8. Never use trading capital to pay development bills.

## Budget status
Maintain `budget-ledger.csv` when implementation begins. Record actual spend and remaining ceiling.
